- C 编号用嘉立创接口核实，型号与名称一致；人民币价格和库存取自立创商城，核实日期 2026-10-02。

- 封装、符号、3D 模型锁定；孔径和焊盘尺寸由脚本从封装文件读出，不手填。

## 与 Codex 版相比改了什么

- Codex 版 60 条全是 C 级占位；本版按厂家图纸把 72 条做到 B 级，规范 ✅ 的 14 条直接引用 V1.1 封装，定为 A 级。
- 检查脚本重写，现在会检查脚距、孔径、环宽、1 脚方焊盘、3D 文件、符号引脚、型号一致、PDF 真伪、尺寸图重复。
- 自测时发现脚距容差 ±0.05 分不出 XH 的 2.50 和 2.54，已收紧到 ±0.02。

## 做选型时发现并处理的问题

| 问题 | 处理 |
|---|---|
| XKB DC-005 的立创 EDA 封装：槽孔方向和本体位置都与厂家图不符 | 按厂家推荐 PCB 图重画（1、2 脚槽孔垂直于插头，3 脚平行）；加了 EDGE 线和插口箭头；3D 改用 KiCad 官方通用 DC 座模型对位 |
| 首韩 Type-C 6P 的立创 EDA 封装比厂家图偏 0.1 mm | 按厂家图重画，贴片脚向后加长 0.2 方便烙铁 |
| 官方 3296W 封装环宽只有 0.32 | 焊盘加大到 1.6 |
| LGE 1N4733A 引线最粗 0.95，官方 DO-41 的 1.1 孔插不进 | 新建 1.2 孔版本 |
| TO-220 引脚最宽 0.97，官方 1.1 孔余量不足 | 新建 1.2 孔立装封装；按脚序分两个版本：GND-OUT-IN（1117/1085）和 IN-GND-OUT（7805），丝印印出脚名 |
| CR2032 座 BS-07 官方封装环宽 0.25 | 焊盘加大到 2.6 |
| 本机 KiCad 官方库缺 PJ-102AH、HRO Type-C、BS-07 的 3D 模型 | 复制一份封装（铜皮不变），换上立创 EDA 模型并对位 |
| 原选 CR2032-BS-6-1 是贴片件 | 换成直插 BS-07 |
| 原选 EL817 下载不到规格书 | 换成夏普原厂 PC817X |
| Type-C 2P 没有 CC 脚，C-C 线不供电 | 删除，改用 6P |
