# 第三批（传感器、执行器、通信、电源模块）完成报告

日期：2026-10-02，云端完成。数据在 `src/b3_modules.yaml`，模块底板封装和符号在 `tools/module_defs_b3.py`。

## 结果

69 条：传感器 48、执行器 10、通信 5、电源模块 6。A 级 1（SEN-009 M1820 探头，V1.1 实焊验证），其余 68 条都是 C 级。其中 8 条不上板（防水探头、M1820、5 个电源模块、18650 电池），用导线或端子连底板。

为什么基本都是 C 级：这些模块是淘宝通用板，没有厂家机械图；云端也打不开淘宝和大多数厂家站。按规则"没有可靠尺寸图的定为 C 级"，没有一条冒充 B 级。

上板方式统一：底板只焊带脚名丝印的直排针（`StudentHW:Module_Hdr_<名>_<N>P`，2.54mm，按 HDR-001 的 B 级排针图），模块用杜邦线按脚名一一对接。这样底板封装不依赖模块外形，不同商家的版型脚序不同也不会把板子做废。要把模块直接插排母时，先对照模块丝印确认顺序相同（每条的 `mount` 和 `pitfalls` 都写了）。

例外：
- HLK-LD6002 / LD6002C：用 V1.1 已验证的 2.0mm 1×8 排母（SKT-003，A 级）。
- NRF24L01：2×4 排母。
- ACT-003 松乐 SRD-05VDC-SL-C 裸继电器：直接上板，用 KiCad 官方 SANYOU SRD 封装，与 GitHub 公开转存的松乐规格书钻孔图逐脚相差 ≤0.05。定 C 级：图上看不清哪几只是扁脚，NO/NC 对应焊盘按官方符号；C35449 没能用接口核实（离线警告）。焊前对照继电器底面接线图。
- SEN-007 DS18B20（TO-92，XBLW 国产兼容）：Maxim 原版规格书取自 GitHub，C18723599 经 jlcparts 镜像核实。定 C 级：规格书正文没有 TO-92 外形和脚径图。

**针序来源**：模块脚序多数来自教程站或商家资料（二手资料），每条 notes 写了来源；底板丝印印的是脚名，到货先对照模块丝印再接线。

每条都写了：针序（按模块丝印）、怎么认 1 脚、电气字段（`src/electrical.yaml`：供电范围、电平、是否耐 5V、I2C 地址和可改地址、板上上拉、电流）、规格书链接、坑。

## 没做到闭环的部分（如实写）

- **规格书 PDF 和尺寸图截图**：67 条在 `evidence/` 里没有文件，只在 `datasheet_url` 写了链接（规格书或教程页）。云端下载不了这些站点。检查脚本对"没有 C 编号、evidence 列为空"的条目不查 PDF，所以检查是通过的，但这不等于闭环。清单见 `待确认.md` 第七节。
- **电流**：111 条电气数据里，典型电流 85 条、峰值电流 96 条写"未核"（没有可靠出处就不写数字）。
- **出处可信度**：电气参数很多来自教程站或商家资料，`src_ref` 和 `key_params` 括号里写了来源类型（规格书 / 教程站 / 商家资料），用前看一眼。
