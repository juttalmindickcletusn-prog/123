# 常用元器件库（StudentHW）

给本科毕设、大创这类学生硬件项目用的选型与封装库。每个条目都已闭环：

- 立创 C 编号已用嘉立创接口核实（型号、厂家、价格、库存）；
- 有厂家规格书 PDF 和尺寸图截图；
- 引脚定义写明怎么认 1 脚；
- KiCad 封装、符号、3D 模型都已锁定，并由脚本逐条检查过。

第一批（通用元件）共 87 条：A 级 14 条，B 级 72 条，C 级 1 条。

## 先看哪里

| 想做什么 | 看这个 |
|---|---|
| 选型，快速查型号、价格、封装 | `常用元器件清单.md` |
| 看封装图、符号图、尺寸证据 | `reports/preview.html`（浏览器直接打开） |
| 全部字段（35 项 + 检查用 5 项） | `parts.csv`（UTF-8，Excel 可直接打开） |
| 还没定的事、已删掉的条目 | `待确认.md` |
| 这一批做了什么、检查结果 | `reports/batch1_报告.md`、`reports/检查汇总.md` |

## 在 KiCad 里使用

1. 设置路径变量：在 KiCad 的「偏好设置 → 配置路径」中，新增 `STUDENTHW_DIR`，值为本文件夹的完整路径。自建封装的 3D 模型靠这个变量定位。
2. 添加封装库：在「偏好设置 → 管理封装库」中新增 `StudentHW`，路径填 `${STUDENTHW_DIR}/kicad/StudentHW.pretty`。
3. 符号全部用 KiCad 官方库，不需要另加符号库。每个条目用哪个符号，看 `kicad_symbol` 列。
4. 画原理图时，把 `kicad_footprint` 列的封装名原样填进元件属性。引脚号已经检查过与符号一致。

## 改数据后怎么重建

只改 `src/*.yaml`，不要直接改 `parts.csv`。然后运行：

```bash
python tools/run_all.py
```

它依次完成以下步骤，结果写入 `reports/检查汇总.md`：

1. 生成自建封装；
2. 生成 `parts.csv`；
3. 封装、符号、证据三项检查；
4. 检查脚本自测；
5. 测试板 DRC 和渲染；
6. 生成预览页和清单。

新增条目或要刷新价格库存时，先联网运行：

```bash
python tools/fetch_evidence.py 编号1 编号2
```

它会调用嘉立创和立创接口，并下载规格书。然后截尺寸图：

```bash
python tools/render_dim.py 编号 页码 x0 y0 x1 y1 名字
```

## 检查脚本查什么

| 脚本 | 检查内容 |
|---|---|
| `check_footprints.py` | 封装存在；焊盘数 = 脚数；脚距与 CSV 相差 ≤0.02（能分出 XH 的 2.50 和 2.54）；孔 ≥ 引脚最大尺寸 +0.2；环宽规则；有极性件 1 脚方焊盘；有 courtyard 和 Fab 层；3D 模型文件存在 |
| `check_symbol_pins.py` | 符号存在，符号引脚号集合 = 封装焊盘号集合 |
| `check_evidence.py` | C 编号对应的型号与 CSV 一致；规格书是真 PDF 且能搜到型号（图片型 PDF 须注明人工读图）；尺寸图存在、不是空白页、不同条目不能用同一张图 |
| `selftest/run_selftest.py` | 故意改错 15 处，确认上面三个脚本都能报出来 |

环宽规则：孔 ≤0.9 时环宽 ≥0.4，孔 >0.9 时环宽 ≥0.5。

- 排针、XH、PH、TO-220 这类条目受脚距限制放不下大焊盘，在 `ring_min_mm` 列写了放宽值，并在 notes 里写明理由。
- A 级封装已经实焊，豁免环宽检查。
