# 数据可行性评估（中国城市体育景观 SCI 论文，3–5 个月周期）

> 后台调研原始报告整理稿。仅通过搜索摘要获取信息（lbsyun.baidu.com、lbs.amap.com、envi-met.com、metro.strava.com、mdpi.com、frontiersin.org、pmc.ncbi.nlm.nih.gov 等站点被会话网络策略拦截），配额/价格数字均【未核实】，使用前须登录对应平台确认。

## 1. POI 与体育场地统计
- **高德 Web 服务 API**：搜索 POI 2.0（关键字/周边/多边形/ID）。2022-06 起个人认证开发者日配额与 QPS 下调；单次 count 上限 1000，需网格切分抓取。体育休闲服务大类 080000（运动场馆 080100 等）。坐标 GCJ-02。一座大城市体育 POI 全量 1–3 天。
- **百度地图开放平台**：地点检索个人 100 次/日、3 QPS；企业试用 2,000 次/日；企业授权 50,000 次/日【未核实日期】。路径规划 API 已被西安 Buildings 2022 公园可达性论文用于算步行/骑行/驾车时间。坐标 BD-09。个人账号不够用，建议双源（高德抓全量 + 百度补漏/算路）。
- **体育公园名录**：未找到国家层面的"全国体育公园名单"。宏观口径：截至 2024 年底全国占地 ≥4 万㎡ 体育公园 1300 余个（2025-08 国新办）；"十四五"新建/改扩建 1900 余个；2023 年中央彩票公益金支持 283 个体育公园/全民健身中心项目。操作：市/省体育局公告 + POI 关键字"体育公园"交叉自建名录，论文中注明（长沙 PLoS ONE 2023 用 13 个体育公园、北京 J. Resources & Ecology 2024 即如此）。上海有《体育公园建设运营管理导则（试行）》可作设计要素编码依据。
- **全国体育场地统计调查**：2024 年（2025-03 发布）体育场地 484.17 万个、42.3 亿㎡、人均 3.0㎡；田径 20.93 万、游泳 3.97 万、球类 303.62 万、冰雪 2678。省/市公报 PDF 可得（河南、常州、平顶山等），**仅汇总指标，无点位**。

## 2. 街景影像与语义分割
- **百度全景静态图 API** 仍在线（文档更新 2026-03-20，api.map.baidu.com/panorama/v2），但一页标注"高级权限，需付费开通"，与旧页"免费"冲突【未核实】。学术研究仍大量使用（洛阳 Sustainability 2025；南京 Frontiers Ecol Evol 2026 用 118,830 张全景）。非官方库：streetlevel、sv-dlp、pycitydata（可能随时失效）。
- **腾讯街景**疑 2021 起停更；高德街景已停；Google 大陆无覆盖；Mapillary 中国覆盖极低。
- **自采全景**：Insta360/理光 Theta + GPS，公园尺度 1–2 天完成，是体育公园内部空间最可控方案（街景 API 不进公园内部）。
- **语义分割**：SegFormer / Mask2Former（ADE20K 150 类，含 tree/grass/plant/sky/building/person）HuggingFace 预训练权重直接可用，方法成熟。

## 3. 轨迹与人群热力
- **Strava Metro 学术计划**：年度申请（2026 周期 2025-09-08 至 10-23），中国列为服务受限国家，覆盖稀疏 → **不可行**。
- **Keep/悦跑圈/咕咚**：无官方开放数据；仅见清华团队 2026 ACAH 会议报告（北京五环内 66,983 条 Keep 轨迹）。抓取需登录、涉个人位置信息（PIPL 高风险）。替代：少量公开"热门路线"作定性补充，或志愿者自采（知情同意）。
- **百度热力图/慧眼**：学术使用活跃且 SCI 接受：福州 131 个公园节假日活力（PLoS ONE 2024）；成都公园-商业活力（JAABE 2025）；长沙百度慧眼人口热力 + 可解释机器学习（Land 2026 15(2):231）；成都三类公园（Land 15(10):1812）。途径：商业授权（价格未公开）或定时抓取网页热力瓦片（合规灰色，但论文普遍写 "collected via Baidu Map heat map"）。
- **腾讯宜出行**疑停更；**手机信令**（智慧足迹等）需机构签约、数万元以上、1–3 月 → 不现实。

## 4. 社交媒体文本
- **技术**：大众点评有字体加密、登录验证；单城体育场馆 50–200 个 POI、数千至数万条评论用八爪鱼/自写脚本 1–2 周可得。美团 App 评论较易；小红书限流；微博位置接口基本不可用。
- **法律**：不绕过登录/验证码、不采个人身份信息、仅公开评论文本并匿名化、低频、学术非商用。
- **期刊接受度（已发表）**：Sustainability 2022 14(19):12741 北京公园 Dianping；Forests 2024 15(9):1633 北京三森林公园 Dianping NLP+IPA 体力活动体验；Forests 2024 15(1):213 杭州公园微博 CES；Sustainability 2025 17(4):1725 香山 20,087 条美团评论 LDA+IPA；Applied Sciences 2025 15(7):3946 澳门 12 公园；PLoS ONE 2025 e0319476 体育场馆在线评论 BERT 情感挖掘；Applied Sciences 2026 16(15):7631 旧工业厂房改造体育综合体美团+点评 LDA+DistilBERT；Discover Sustainability 2025 中国体育公园在线评论情感（ESCI）；J. Resources & Ecology 2024 北京体育公园 POI + 旅游评论。公开数据集：上海体育场馆 Dianping 评论（Mendeley Data 2024）可直接复用。
- **结论**：MDPI Land/Sustainability/Forests/Applied Sciences、PLoS ONE、Frontiers 明确接受点评/美团/微博评论数据，方法中写明平台、时段、数量、去重与匿名化即可。

## 5. 微气候模拟
- **ENVI-met**：免费版已取消，仅 30 天 Lite（网格约 50×50×40）；Capterra 列 €290/用户/年起；机构许可约 €5k/套【未核实】。
- **SOLWEIG（UMEP for QGIS）**：免费开源，v2025a 在 Processing Toolbox，输出 Tmrt→PET/UTCI；需 DSM/CDSM + 气象（ERA5 或自测）。**推荐主方案**。
- **Ladybug Tools** 1.10（2026-03）免费但需 Rhino。
- 文献：西安校园四类场地 PET/SET/UTCI，运动场 54.4% 报热（Sci Rep 2024）；桂林公园儿童 UTCI（Sci Rep 2025）；严寒城市不同运动类型 UTCI 修正阈值（2022）；Sustainability 2026 18(4):2104 运动场参数化实验 + UTCI。**未检到 2023–25 年"模拟 + 体育公园/球场 + PET/UTCI + 景观要素优化"合体论文 → 空白点。**

## 6. 遥感 / GIS 基础（全部免费）
- Sentinel-2 NDVI、Landsat LST（GEE，Ermida 2020 开源代码）；WorldPop 2024/2025 中国 100 m 栅格（CC BY）；LandScan Global 2023 免费注册下载。
- 2SFCA：ArcGIS Pro 免费工具箱（Hashtarkhani 2024）、r2sfca（PyPI）、TU Dresden DVA 工具箱。OSM 路网 + 百度/高德路径规划算实际出行时间（上海 JTH 2025、西安 Buildings 2022 已用）。

## 7. 中国体育/景观专题数据
- 国家体育总局统计只通过新闻稿/公告发布；市级年鉴/体育局年报通常有"体育场馆数"。
- 杭州亚运：赛后官方口径 54 竞赛 + 30 独立训练场馆，分布杭州及宁波、温州、湖州、绍兴、金华（分项目名单见杭州日报 2022-08-31）。
- 北京 2022：39 个场馆（12 竞赛、3 训练、24 非竞赛），12 竞赛场馆中 11 个为 2008 遗产。

## 8. 问卷 / 行为观测
- SOPARC 中国实例：南昌 8 公园、12 天、每园 48 次观测、75,678 人；香港 9 公园 288 场次。经验法则：每园 ≥2 平日 + 2 周末、每日 3–4 时段、持续 2–4 周。
- 问卷样本量（3 区刊已接受）：Land 2025 三公园 701 人；Frontiers PH 2025 成都 307 人 PRS 中介模型；北京 22 公园 225 + 1346 人。300–500 有效问卷 + SEM/有序 Logit 足够。PRS 中文版已验证（Frontiers PH 2025-10）。

## 10. 可行性总表
| 数据源 | 获取途径 | 成本 | 时间 | 风险 |
|---|---|---|---|---|
| 高德 POI | Web API 网格切分 | 个人免费（配额低） | 1–3 天 | 低 |
| 百度 POI | 地点检索 API | 个人 100 次/日【未核实】 | 1–2 周 | 中，作补充 |
| 体育公园名录 | 体育局公告 + POI 交叉 | 0 | 1 周 | 中，需自建并说明 |
| 体育场地统计 | 体育总局/省市公报 | 0 | 1 天 | 低，无点位 |
| 百度全景街景 | 官方 API（权限未核实）/非官方库 | 未知 | 1–2 周 | 中-高 |
| 自采全景 | 360 相机 + GPS | 2–5 千元 | 1–2 周 | 低 |
| 语义分割 | HuggingFace 预训练 | 0 | 1 周 | 低 |
| Strava Metro | 年度申请 | 0 | 不可控 | 高 → 不建议 |
| Keep 等轨迹 | 无官方 | 0 | — | 高 |

| 手机信令 | 机构签约 | 数万–数十万 | 1–3 月 | 高 |
| 点评/美团评论 | 八爪鱼/脚本 | 0–数百元 | 1–2 周 | 中 |

| SOLWEIG/UMEP | QGIS 免费 | 0 | 1–2 周 | 低 |
| Sentinel-2/Landsat/WorldPop/LandScan/OSM/2SFCA 工具 | 免费 | 0 | 1 周 | 低 |

| SOPARC/问卷 300–700 人 | 现场 | 人工 | 3–6 周 | 低，需伦理审查 |

**推荐组合**：高德+百度 POI → WorldPop → OSM/地图 API 出行时间 → 2SFCA/Gini；叠加百度热力图多周采样（活力）与点评/美团评论（感知）；选 2–3 个体育公园自采全景 GVI + SOLWEIG 热舒适 + SOPARC/问卷 POE。避免 Strava、信令、宜出行。
